6 gaps to fill. No change to the Channel-based async write architecture.

Updated Flow

1 User long-presses album → "Fetch album info"
2 Gap 7: Collect albumArtist from all tracks, compute mode
3 Gap 4: Build query — if VA detected, skip artist constraint
4 searchReleases(query) → results dialog
Gap 4: If <3 results and query had artist → retry without
Gap 1: Dialog has "Fetch cover art" checkbox
Dialog shows more detail: release date, format, track count
5 User picks release + cover art preference
6 getReleaseMetadata(releaseId) → ReleaseMetadata
Gap 3: API inc param extended: +release-groups
ReleaseDto now captures: release-group MBID, artist MBIDs
7 Gap 1: If cover art requested, fetch via getCoverArtBytes
8 Build Metadata per track:
albumArtist, year, all genres (Gap 2)
coverArtBytes (Gap 1, if requested)
mbAlbumId, mbReleaseGroupId, mbAlbumArtistId (Gap 3)
9 Enqueue to _pendingMetadata Channel
10 Gap 5: Count writes, show final snackbar ("Updated 10/12")
11 MetadataWriter writes MBIDs to tags + Room DB updated
