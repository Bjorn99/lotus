Genre Joining (Gap 2)

In handleAlbumInfoEvent, replace:

val genre = releaseMetadata.genres?.firstOrNull()

With:

val genre = releaseMetadata.genres?.joinToString(" / ")

jaudiotagger's FieldKey.GENRE writes the whole string. For ID3v2, multiple genres can be null-separated — but " / " is the convention this app already uses (see SearchResultItem genres display). Consistent.

Write Result Counting (Gap 5)

Change private val _pendingMetadata from Channel<Pair<Track, Metadata>> to carry a completion callback:

data class PendingWrite(track: Track, metadata: Metadata, onComplete: (Result) -> Unit)

The ViewModel queues N writes, each with a callback that increments a counter. When counter == N, fire the final snackbar: "Updated 10 tracks" or "Updated 8 of 12 tracks."

Alternative (simpler): use a CompletableDeferred per write, collect in ViewModel coroutine. Same effect, no callback lambda allocation.
