Error Handling

| Scenario | Behavior | |---|---| | Album has 0 tracks | Short-circuit, no query (existing guard: firstTrack check) | | All tracks have null album | Skip (existing guard: albumName check) | | All tracks have null albumArtist | Artist constraint uses track artist mode; <3 results triggers no-artist retry | | Cover Art Archive returns 404 | Skip cover art, still apply text metadata. No error to user. | | Cover art fetch network error | Skip cover art, still apply text metadata. Log warning. | | Release search returns 0 after retry | Dialog shows "No results" (existing behavior) | | Write fails for some tracks | Count tracked. Final snackbar: "Updated 8 of 12 tracks" | | Write fails for ALL tracks | Count tracked. Final snackbar: "Failed to update tracks" | | Rate limiter exhausted during retry | Standard Channel suspension — transparent to user | | Track in unsupported format | Skipped during queueing (existing guard: `format !in unsupportedWriteFormats`) | | MBID already exists in tags | Overwritten (idempotent — same release = same MBIDs) |

Edge Cases

  • Single-track album: Mode = that track's artist. Works fine. May not trigger VA detection properly but one-track compilations are rare.
  • Album name with quotes: escapeLuceneQuery handles this (existing code)
  • Release with no genres/tags: genre stays null, no crash
  • Release with no date: year stays null, no crash
  • Release-group missing from API response: nullable field, just omitted
  • Artist credit with no MBID: nullable field, individual artists in credit lists may lack IDs
  • User rotates phone during fetch: StateFlow survives config change
  • User dismisses dialog during fetch: Coroutine continues in viewModelScope, writes proceed. Acceptable — metadata is metadata.

Testing Strategy

  • Unit test: query builder — verify VA detection, mode selection, query string construction
  • Unit test: JSON deserialization — ReleaseDto with release-group, artist IDs present and absent
  • Unit test: MetadataWriterImpl — verify FieldKey writes (can mock AudioFileIO)
  • Integration test: Room migration — verify track_metadata table creation
  • Manual test: VA album — fetch metadata for a Various Artists compilation
  • Manual test: Cover art — fetch with and without checkbox, verify tag written
  • Manual test: Write counting — fetch on album with 12 tracks, verify correct snackbar
