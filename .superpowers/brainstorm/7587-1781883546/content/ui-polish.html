Implementation

Cover art checkbox row:

Row(verticalAlignment = CenterVertically) {
  Checkbox(
    checked = state.fetchCoverArt,
    onCheckedChange = { onFetchCoverArtToggle(it) }
  )
  Text("Fetch cover art")
}
Text("MusicBrainz / Cover Art Archive",
  style = MaterialTheme.typography.labelSmall,
  color = MaterialTheme.colorScheme.onSurfaceVariant,
  modifier = Modifier.padding(start = 48.dp)
)

States:

  • Loading (isLoading): Single centered CircularProgressIndicator. No LinearProgressIndicator — that pattern is for the search sheet, not a selection dialog.
  • Results ready: LazyColumn of SearchResultItems (existing), then cover art checkbox, then ProviderText attribution.
  • Fetching release (isFetchingRelease): Fade out results, fade in CircularProgressIndicator. No separate indicator row.
  • No results + not loading: "No results found" text.

Key design decisions:

  • Keep AlertDialog — consistent with context menu dialog and SearchHintDialog
  • Border highlight on selected result (using Modifier.border with primary color) — clear which item is being hovered/tapped
  • Checkbox uses Material 3 defaults (no custom styling needed)
  • Attribution line uses labelSmall typography (same as existing ProviderText pattern)
  • Divider separates results from the checkbox — visually groups the action from the content
  • Default fetchCoverArt = true (opt-out, not opt-in — cover art is the expected behavior)
